* Marvell PXA988 / PXA986 Clock and Reset Controller

The Marvell PXA988 (and PXA986) clock subsystem generates and supplies clocks
and resets to various controllers within the SoC across the MPMU, APMU, APBC,
APBCP, APBS, and CIU register blocks.

Required Properties:

- compatible: should be "marvell,pxa988-clock".
- reg: physical base addresses and lengths of the MPMU, APMU, APBC, APBCP,
  APBS, and CIU register regions, in that order.
- reg-names: should be "mpmu", "apmu", "apbc", "apbcp", "apbs", "ciu".
- #clock-cells: should be 1.
- #reset-cells: should be 1.

Each clock or reset line is assigned an identifier and client nodes use the
clock controller phandle and this identifier to specify the clock or reset
which they consume.

All these identifiers can be found in <dt-bindings/clock/marvell,pxa988.h>.

Example:

	soc_clocks: clock-controller@d4050000 {
		compatible = "marvell,pxa988-clock";
		reg = <0xd4050000 0x1000>,
		      <0xd4282800 0x0400>,
		      <0xd4015000 0x1000>,
		      <0xd403b000 0x1000>,
		      <0xd4090000 0x1000>,
		      <0xd4282c00 0x0400>;
		reg-names = "mpmu", "apmu", "apbc", "apbcp", "apbs", "ciu";
		#clock-cells = <1>;
		#reset-cells = <1>;
	};
