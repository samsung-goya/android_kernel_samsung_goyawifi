Marvell 88PM822 Software Fuel-Gauge Battery

This node is a child of the Marvell 88PM822 PMIC MFD node (marvell,88pm822).

Required properties:
- compatible: must be "marvell,88pm822-battery"

Optional properties:
- power-supplies: phandle to the charger power_supply node (e.g. smb328-charger)

Example:
	pmic@30 {
		compatible = "marvell,88pm822", "marvell,88pm800";
		...
		battery: battery {
			compatible = "marvell,88pm822-battery";
			power-supplies = <&charger>;
		};
	};
